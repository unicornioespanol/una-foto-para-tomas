# Una foto para Tomás

Интерактивная книга на испанском, 7–10 лет. Подготовка → история с двумя выборами → задания → страница альбома. Исходные `data/story.json` и `data/activities.json` сохранены.

## Открыть книгу

**Открыть `offline/Una foto para Tomas.html` двойным щелчком.** Передавать нужно **всю папку `offline`**, включая `assets/audio`: 29 MP3 намеренно лежат отдельно от HTML. В HTML включены приложение и рисунки (около 29 МБ), но не аудио. Установка и сервер не нужны; исследовательская аналитика в file:// выключена. Корневой `Una foto para Tomas.html` также работает, если рядом сохранена папка `assets/audio`.

Используется готовая записанная озвучка: пауза/продолжение с текущей позиции и повтор с начала. Системный TTS не вызывается. Если аудиофайл недоступен, текст и навигация остаются рабочими. Полная карта MP3, ограничения проверки и точечная ретушь: [AUDIO_UI_REPORT.md](AUDIO_UI_REPORT.md).

## Локальная аналитика с базой

Добавлен настоящий Node.js backend, PostgreSQL, согласие взрослого, IndexedDB-очередь, автоматическая доставка и защищённая `/admin/analytics`. Локально PostgreSQL-движок PGlite сохраняет данные в `runtime/dev-postgres/`; production подключает PostgreSQL через `DATABASE_URL`. Хостинг и домен откладываются по решению пользователя.

Пошаговый запуск, первый администратор, схема согласия, production/HTTPS, backup и retention: **[README_SERVER.md](README_SERVER.md)**. После создания администратора запустить `npm.cmd run server`; книга и API доступны на одном origin. Исследовательский режим включается явно через `TELEMETRY_MODE=research`; без согласия книга работает, события не отправляются.

## Разработка

Из этой папки в PowerShell:

```powershell
npm.cmd install --cache .npm-cache
npm.cmd run dev
```

Открыть адрес Vite, обычно `http://127.0.0.1:5173/`. Команда `npm.cmd` работает при системном запрете на запуск `npm.ps1`.

```powershell
npm.cmd run check
npm.cmd run build
npm.cmd run preview
```

`build` создаёт сайт в `dist/` с отдельными `assets/audio/*.mp3`, корневой HTML и переносимую папку `offline/`. Для просмотра `dist/` используется HTTP-сервер. Для аналитики — существующий Node.js backend по инструкции README_SERVER.md; для обычного чтения backend не обязателен.

## Возможности

- Обложка, продолжение, четыре компактных подготовительных шага и пропуск подготовки.
- Все 13 узлов; 9 страниц на прохождение; четыре сочетания route × ending; возврат; правильные вариантные реплики и состояние фото/рисунка.
- Один файловый аудиоконтроллер: 14 сюжетных MP3 и 15 коротких записей, точная пауза/продолжение и повтор с начала. Остановка при переходе и скрытии вкладки; без автозапуска, синтеза и добавочных звуков. Подсветка без таймкодов не имитируется.
- Узнавание семьи, детали портрета, предположение, сопоставление предметов; порядок карточек касанием, кнопками или перетаскиванием; интерпретация без оценивания.
- Конструктор фраз, сохранение, PNG и копирование подписи; необязательный другой маршрут.
- Проверяемое сохранение `book:una-foto-para-tomas:v1`, восстановление, обработка повреждённой записи и недоступного хранилища. Сброс с подтверждением только для этой книги.
- Адаптация, клавиатура, доступные подписи, режим без звука, reduced motion. SVG-персонажей нет.

## Графика

s02/s04 сохранены. Из `book_update` подключены все 46 PNG: 28 сцен с desktop/mobile и вариантами общих финалов, карточки подготовки и воспоминаний, девять рисунков альбома. Мастера проверены по SHA-256; WebP-копии используются для доставки без изменения оригиналов. Альбом меняет картинку по месту/предмету и экспортирует ту же композицию в PNG. Заглушек на поставленных сценах больше нет. Карта подключения: `data/scene-manifest.json`, `data/activity-assets.json`; исходный пакет сохранён.

Учебные экраны помещаются при 100% на 1280×720, 1366×768, 1440×900 и 1920×1080; на узких/низких окнах допускается естественная прокрутка. Hotspot работает на крупном отдельном портрете; matching — слово → картинка с `Comprobar`.

## Проверки

`npm.cmd run check` — логика, речь с подставным API, сохранение и повреждённые данные.

При работающем Vite: `npm.cmd run test:browser` — четыре маршрута, задания и скачивание PNG, смена выбора, восстановление, сброс, адаптация. Использует Playwright Chromium; путь можно задать в `BOOK_BROWSER_PATH`, адрес — в `BOOK_TEST_URL`, включая `file:///…/Una%20foto%20para%20Tomas.html`. Результаты — `test-results/`.

Объём фактической проверки и ограничения: [QA_REPORT.md](QA_REPORT.md). Публикация не выполнялась, согласно исходному брифу.

Дополнительно: `npm.cmd run test:layout`, `npm.cmd run test:server`, `npm.cmd run test:research`. Серверный end-to-end сам поднимает временную локальную базу/сервер и проверяет запись, очередь, админку, отзыв и перезапуск.

Для текущего аудио/UI: `npm.cmd run test:audio`, `npm.cmd run test:audio-ui` при работающем Vite. Они также принимают `BOOK_TEST_URL` для preview/build или file://. Новые аудиотесты входят в `npm.cmd run check`. Серверная архитектура и схема БД при интеграции аудио не менялись.
