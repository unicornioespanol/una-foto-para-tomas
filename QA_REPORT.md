Сюжет, занятия, графика и все MP3 сохранены; контентные SHA-256 проверены. Сведения ниже описывают прежние этапы; старое ограничение об отсутствии отдельного PostgreSQL-процесса относится к тем прошлым проверкам.

## Автоматически проверено

- **21 проверка модулей:** 13 узлов, четыре сочетания route × ending, девять экранов на маршрут, вариантные реплики, возврат, запрет пропуска выбора; пауза/повтор/отмена речи, поздние события отменённой или ошибочной речи, отсутствие API, пустой/поздний список голосов, запрет подстановки английского; сохранение и проверка достижимости истории, повреждённые данные, блокировка localStorage.
- **Chromium через Playwright:** прохождение четырёх сочетаний через настоящие кнопки, фото/рисунок в финале, правильные вариантные реплики, обновление страницы и продолжение, возврат на выбор и смена ветки.
- **Подготовка:** правильное/неправильное узнавание семьи, детали портрета, сохранение предположения, сопоставление четырёх предметов.
- **После чтения:** неправильная и правильная расстановка обеих веток, перестановка карточек, интерпретация без оценки, выбор опорной картинки, конструктор грамматически правильных фраз.
- **Экспорт:** четыре реальных скачивания PNG, проверены просмотр результата и содержание подписи. Временный портрет и пометка о неготовой иллюстрации остаются в PNG.
- **Сохранение:** ответы сохраняются при простом возврате; смена маршрута их очищает; перезапуск не удаляет посторонний ключ localStorage; повреждённая запись возвращает на обложку с сообщением.
- **Устойчивость:** отдельный браузерный контекст без Web Speech API и с запрещённым localStorage позволяет читать и листать.
- **Размеры:** 360, 390, 768, 1024, 1440 CSS px; горизонтальный viewport 844×390; 720×500 как проверка компоновки при уменьшенном вдвое доступном пространстве. Горизонтального скролла в проверенных экранах нет. Отдельно проверены альбом и подготовительные экраны. Прокрутка/фокус сохраняются при выборе в задании.
- Тот же сценарий браузерной проверки выполнен для самостоятельного HTML по `file://`.

## Ограничения этой проверки

- Нет физических iPhone/Android и ручного прогона Safari, Firefox, Edge. Это остаётся проверкой перед финальным выпуском, как предусмотрено брифом. Chromium-viewport не заменяет реальный телефон.
- Настоящее браузерное масштабирование 200% отдельно не проверялось; проверено эквивалентное ограничение CSS-ширины.
- Реальные испанские системные голоса на телефонах и качество звучания не оценены. Проверены логика TTS, состояния ошибок и текстовый режим; системный синтез может зависеть от сети.
- Копирование через Clipboard API зависит от разрешений браузера; при отказе появляется поле для ручного копирования. PNG скачивание проверено.
- Графика остальных сцен, карточек E1/E2 и девяти вариантов альбома ещё не отрисована. В книге/экспорте это обозначено явно. Полный перечень — `ASSETS_NEEDED.md`.
- Для file:// поведение localStorage зависит от браузера и расположения файла. Резервный режим работает в памяти вкладки. Сохранение не синхронизируется между устройствами.

Публикация не выполнялась: по исходному брифу это отдельный этап.
