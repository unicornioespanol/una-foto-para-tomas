# Задание для Codex

Реализуй интерактивную книгу Una foto para Tomás по TECHNICAL_BRIEF.md. Язык испанский, возраст 7–10 лет. Сценарий утверждён: data/story.json и data/activities.json — источники текста и заданий.

Графика — PNG/WebP. Используй пять файлов assets/references как стилевые и композиционные ориентиры. SVG-персонажи предыдущей версии отклонены: не создавать и не восстанавливать их. Все реплики, кнопки и управление — HTML.

Сначала собери работающие s02 и s04 для компьютера и телефона: настоящий текст, временная озвучка Web Speech API, кнопки выбора с переходами a05/b05 и возврат. Прочие сцены пока могут иметь явную заглушку Ilustración en preparación. Не выдавай заглушки за готовую отрисовку и не подставляй одинаковую неподходящую иллюстрацию во все эпизоды.

Затем подключи сценарий целиком: 13 узлов, два выбора, четыре сочетания маршрутов/финалов. Сохраняй фото/рисунок в финальных сценах. Добавь pre-reading и post-reading, localStorage и адаптацию. Используй опорные src/story-engine.js и src/browser-narrator.js или их эквиваленты с тем же поведением. Не менять утверждённый текст.

После проверки первых страниц составь ASSETS_NEEDED.md: какие иллюстрации ещё нужны, сцена, персонажи, состояние фото/рамки/рисунка, композиции desktop/mobile и действительно необходимые прозрачные слои. Весь недостающий визуал отрисуем отдельно по утверждённому референсу, затем подключим.

Первый результат должен запускаться локально и позволять проверить страницу и выбор на двух размерах экрана. Проведи проверки логики, вёрстки, навигации, отмены речи и отсутствия испанского голоса. Текст доступен без звука. Сборка Vite + HTML/CSS/JavaScript, без обязательного сервера, платных API и фоновой музыки.

Проверки опорных модулей: node --test tools/check.mjs.
